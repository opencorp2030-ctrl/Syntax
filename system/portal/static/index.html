Méthode 2 — Jeton de tunnel

Dans le tableau de bord Cloudflare : Zero Trust → Réseaux → Tunnels → Créer un tunnel (Cloudflared). Ajoute un nom d'hôte public pointant vers http://localhost:80, puis colle le jeton ici.

Sécurité

Le tunnel ne démarre jamais tant qu'un compte utilise encore le mot de passe d'usine. Pour une protection supplémentaire, ajoute une règle Cloudflare Access (gratuit jusqu'à 50 utilisateurs) devant l'adresse de ton Pi : seules les adresses e-mail que tu autorises pourront atteindre cette page.

Comptes de cette machine

Chaque compte a son propre mot de passe et sa propre session (terminal, fichiers). Un compte « administrateur » peut utiliser sudo et gérer les autres comptes.
